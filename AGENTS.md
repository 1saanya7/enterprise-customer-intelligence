# Project constraints

The user requires no additional charges for Google agents or cloud usage.

- Continue local development with fictional sample data and offline tests.
- Do not enable billing, activate subscriptions, provision cloud resources, deploy services, or make paid model/API calls.
- Do not weaken cost_policy.py or the Terraform provisioning guard without an explicit later user instruction changing the spending policy.
- Credentials, free-tier eligibility, promotional credits, and budget alerts alone are not authorization to spend.
- Installing free SDKs and running local validation are allowed. Keep generated caches and credentials out of version control.
- Clearly distinguish the offline implementation from tested live cloud integrations in documentation and resume claims.
